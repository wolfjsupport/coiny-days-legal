# Coiny Days policies

Static bilingual legal pages for GitHub Pages.

## Publish
1. Create a public GitHub repository, e.g. `coiny-days-legal`.
2. Upload `index.html`, `privacy-policy.html`, `terms-of-service.html`, and `style.css` to the repository root.
3. Go to Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save.
4. Wait for GitHub Pages deployment. Check both policy URLs in a private browser window.
5. Add the privacy policy URL to App Store Connect, and link both pages from the game's Settings.

Before publishing, verify SDK behavior, local backups, data deletion, third-party assets, and any future analytics or monetization changes.
